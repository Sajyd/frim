sample-model.glb is a Mixamo humanoid (X Bot) with a full finger rig.
Load it in the editor so GPU / Fast capture can retarget hand gestures.

sample-capture.mp4 is a short single-person clip (Pexels 2795750, rooftop
movement) used by “Use example clip” in the capture modal. Run it with Fast
(in-browser) or Studio 3D (GPU) to produce a demo animation on the sample model.
